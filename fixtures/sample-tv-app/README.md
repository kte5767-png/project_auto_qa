# sample-tv-app

정답 결함 목록(`defects.json`)이 있는 샘플 TV 앱입니다. QA 서비스의 검출률·오탐률을 측정하는 기준입니다 (로드맵 P0-1).

## 실행

```bash
pnpm sample:dev                 # http://localhost:8092
pnpm sample:verify              # 정답 결함이 실제로 재현되는지 검증 (Chrome 필요)
CHROME_PATH=/usr/bin/google-chrome pnpm sample:verify   # 로컬 Chrome 사용 시
```

## URL 파라미터

| 파라미터  | 값                        | 기본값      | 설명                                                                                                                                                |
| --------- | ------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `focus`   | `spotlight`, `class`      | `spotlight` | 포커스 방식. `spotlight`는 실제 `@enact/spotlight`(실제 DOM 포커스, `.spottable`, `data-spotlight-id`), `class`는 CSS 클래스(`focused`) 가상 포커스 |
| `back`    | 양의 정수 키 코드         | `461`       | 리모컨 Back 키 코드 (webOS 461)                                                                                                                     |
| `defects` | `none`, `all`, `D01,D03…` | `none`      | 켤 결함. `none` 상태에서 나온 이슈는 모두 오탐                                                                                                      |

예: `http://localhost:8092/?focus=class&defects=D05,D07`

## 화면

- **홈**: GNB, 썸네일 셸프, Top 10 셸프, 프로모 카드. 크기·간격·포커스 스타일(1.1배 확대 + 4px 테두리)은 Figma `Top 10 01` 프레임 값과 같습니다. 글자 크기·색은 이 앱 자체 기준입니다.
- **상세**: 카드에서 OK. Back으로 홈 복귀 시 진입했던 카드에 포커스
- **검색**: GNB Search에서 OK. 화면설계서 4.1 와이어프레임 배치를 TV 좌표로 옮김. Back으로 홈 복귀 시 GNB Search에 포커스

시작 상태는 홈, 썸네일 1번 카드 포커스입니다. 화면 크기는 1920×1080 고정입니다.

| id  | 분류   | 내용                                            | 재현 키   |
| --- | ------ | ----------------------------------------------- | --------- |

| D02 | GUI    | 프로모 버튼 배경색 #F2F2F2→#D9D9D9              | ↓ ↓       |
| D03 | GUI    | Top 10 항목 간격 40→48px                        | ↓         |

| D05 | GUI    | Top 10 포커스 테두리 없음 (확대만)              | ↓         |
| D06 | GUI    | 프로모 설명 너비 780→560px, 1줄 말줄임          | ↓ ↓       |
| D07 | 포커스 | Top 10 7번 카드 도달 불가                       | ↓ →×6     |
| D08 | 포커스 | GNB Luggage에서 ↓ 반응 없음                     | ← ↓ ↓     |
| D09 | 포커스 | 프로모 버튼에서 ↑ 시 포커스 소실                | ↓ ↓ ↑     |

정확한 기대값·실제값과 채점용 대상은 `defects.json`에 있습니다. `pnpm sample:verify`가 두 포커스 방식 모두에서 각 결함이 재현되는지, 결함이 없을 때 포커스가 기대 위치에 있는지 확인합니다.

## 주의: QA 서비스가 쓰면 안 되는 것

이 앱은 실제 외부 앱 역할입니다. 아래 속성은 채점과 앱 내부용이며, QA 서비스의 검출·매칭 로직에서 쓰면 안 됩니다.

- `data-testid` (채점용)
- `data-sample-nav` (앱 내부 포커스 엔진용)

`data-spotlight-id`는 실제 Enact 앱에도 있는 속성이므로 써도 됩니다.
