# P0-7 TC 엑셀 정규화 스파이크

TC 엑셀을 넣으면 **TC 프로필을 자동 제안**하고, 그 프로필로 **공통 TC 모델로 정규화**한 뒤, **결과 칸에 실제로 써 보고 위치를 확인**합니다 (D-021, D-025, D-028).

```bash
pnpm spike:tc <파일.xlsx...>                          # 파일마다 프로필 제안 + 정규화 + 결과 칸 확인
pnpm spike:tc <파일.xlsx> --profile 확인한-프로필.json  # 사람이 고친 프로필로 정규화
```

결과는 `spikes/p0-7-tc/out/<파일 이름>/`에 생깁니다. **회사 TC 내용이 들어 있으므로 커밋하지 않습니다** (`.gitignore`의 `spikes/*/out/`).

| 파일                | 내용                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `profile.json`      | 자동 제안한 TC 프로필 (시트 종류, 헤더 행, 열 역할, 묶기 기준, 절차 형식, 참조 규칙, 근거, 신뢰도) |
| `cases.json`        | 정규화 결과 (TC → 단계, 결과 칸 위치, 앞 단계 참조, 화면설계서·콜아웃 참조, 자동화 라벨) + 진단    |
| `summary.json`      | 시트별 통계와 결과 칸 쓰기 확인 결과                                                               |
| `result-probe.xlsx` | 단계마다 결과 칸에 `AUTOQA 시트!행` 표시를 쓴 사본 (원본은 그대로)                                 |
| `report.html`       | 위 내용을 사람이 보는 리포트 (시트마다 앞 2개 TC를 펼쳐 수작업 대조용으로 보여 줌)                 |

## 확인하는 것

1. **TC 수·단계 수**: 시트별 수를 수작업(또는 독립 스크립트) 집계와 비교합니다.
2. **결과 칸 위치**: 사본의 결과 칸에 단계마다 다른 표시를 쓰고 다시 읽어, 모든 표시가 기대한 칸에 있는지 확인합니다. 결과 칸 외 값이 바뀌었는지, 결과 칸을 여러 단계가 함께 쓰는지도 셉니다.
3. **원본 보존**: 결과 쓰기는 엑셀 라이브러리로 다시 저장하지 않고 zip 안 시트 XML의 결과 칸만 바꿉니다. 바뀐 zip 파트가 해당 시트 XML뿐인지 리포트에 표시합니다.
4. **자동화 라벨**: 규칙별 단계 수 (음성 안내·보이스·터치·포인터·시스템 진입은 보류, 관리자 설정·네트워크 조작은 수동).

## 프로필 고치기

`profile.json`을 복사해 고친 뒤 `--profile`로 넘깁니다. 시트마다 다음을 바꿀 수 있습니다.

- `include`: 정규화 대상 여부
- `headerRow`, `columns`: 헤더 행과 역할별 열 문자 (`id`, `title`, `category`, `caseNo`, `step`, `precondition`, `action`, `expected`, `result`, `note`, `severity`)
- `groupStart`: 이 역할 칸 중 하나에 값이 있으면 새 TC 시작
- `stepFormat`: `row-per-step`(행마다 한 단계) / `numbered-list`(조작 칸 안 "1. …" 목록을 나눔)
- `referencePattern`, `specIdPattern`, `targetRefPattern`: 앞 단계 참조·화면설계서 ID·콜아웃 참조 정규식 (없으면 `null`)
